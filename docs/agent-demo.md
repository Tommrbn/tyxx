# Asistente local de TYXX en Strand

«Probá un agente» abre una simulación sobre el negocio de TYXX. Podés escribir una pregunta libre o usar sugerencias sobre aplicaciones de IA para el negocio, servicios, presupuesto, comienzo del proyecto y experiencia. Las respuestas exploran consultas, seguimiento de oportunidades y tareas repetitivas mediante agentes de IA, sistemas a medida, automatizaciones e integraciones sujetos a evaluación; consulta inicial sin cargo, propuesta y plazos según alcance, mantenimiento opcional y trabajo con Novartech y el sitio MYOPIALATAM del Congreso Latinoamericano de Miopía desarrollado para Vision Latina. No atribuye a TYXX todos los productos de Novartech ni presenta el proyecto digital de Vision Latina como caso de IA. No garantiza ventas, crecimiento ni ahorros; tampoco publica importes ni fechas fijas. Cuando no hay información confirmada, pide una aclaración concreta y ofrece contacto.

Cada pregunta válida aparece enseguida con «Preparando respuesta…»; la respuesta local se muestra después de al menos tres segundos de espera intencional. La espera no representa razonamiento de un modelo ni actividad de red. Solo se admite una pregunta pendiente; reiniciar cancela su respuesta, mientras cerrar el panel conserva la conversación.

La conversación reciente se desplaza sin ocultar el campo de escritura. «Conversar con TYXX» cierra el panel y lleva a contacto sin adjuntar el chat. «Reiniciar demo» lo borra; cerrar y reabrir conserva hasta ocho intercambios mientras la página siga cargada. Recargar lo pierde. La demo se abre únicamente desde el botón flotante. Sin JavaScript o con el módulo bloqueado, el contacto y el correo estático siguen disponibles.

**Límite:** respuestas deterministas locales, no un modelo de IA conectado. No consulta datos externos, almacena ni transmite preguntas, envía mensajes, reserva turnos ni confirma presupuestos o viabilidad. No ingreses datos personales. Para implementar un agente real habría que acordar fuentes autorizadas, alcance y supervisión humana, y conectar un modelo mediante infraestructura segura por separado.
